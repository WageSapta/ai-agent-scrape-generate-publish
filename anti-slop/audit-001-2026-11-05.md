# Audit 001 - 2026-11-05

## 1. Firecrawl proxy and timeout

Priority: HIGH

Rule violated: Checklist requires `proxy: "stealth"` and a timeout of at least 60 seconds.

Evidence:
- `lib/firecrawl.ts` uses `proxy: "auto"` instead of `proxy: "stealth"`.
- `REQUEST_TIMEOUT_MS` is `30_000`.

Status: FIXED
- `proxy: "stealth"` is configured.
- Firecrawl timeout is now `60_000`.

## 2. OpenRouter model override

Priority: MEDIUM

Rule violated: The integration must force `openrouter/free`, not allow an arbitrary environment override.

Evidence:
- `lib/openrouter.ts` falls back to `openrouter/free`, but `OPENROUTER_MODEL` may replace it.

Status: FIXED
- The model is now hard-coded to `openrouter/free`.

## 3. Cron setup documentation incomplete

Priority: MEDIUM

Rule violated: The checklist requires exact instructions for connecting cron-job.org every 2 hours.

Evidence:
- `README.md` names `cron-job.org` and the every-2-hours schedule, but gives no URL, Authorization header, method, or cron expression setup.

Status: FIXED
- The README now includes the endpoint, GET method, Bearer header, and `0 */2 * * *` schedule.

## 4. SSRF validation is lexical only

Priority: MEDIUM

Rule violated: Enterprise-grade URL validation should cover DNS rebinding and private address resolution.

Evidence:
- `lib/utils.ts` blocks malformed URLs, credentials, localhost, and known private hostname patterns.
- It does not perform DNS resolution or re-resolution after redirect before external scraping.

Status: FIXED
- Added server-side DNS resolution checks before agent and cron execution.
